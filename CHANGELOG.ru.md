# Changelog

Этот же список показывается в приложении после каждого обновления — его можно открыть снова через номер версии в строке состояния. Новые релизы сверху. Также доступно [на английском](CHANGELOG.md).

## 1.3.159 — 2026-10-02

### Новое
- После обновления теперь показывается экран «Что нового» — его можно открыть снова через номер версии в строке состояния.

### Улучшено
- Полный список изменений теперь также доступен на GitHub, в CHANGELOG.ru.md.

## 1.2.158 — 2026-10-02

### Новое
- Выберите цвет или градиент фона и узор из значков для оболочки приложения в «Настройках» — пока один из них активен, рабочая область становится матовым стеклом.

## 1.2.156 — 2026-10-02

### Новое

## 1.2.150 — 2026-10-02

### Новое

### Улучшено
- Расписание обучения по сессиям теперь по умолчанию в UTC, а не угадывает часовой пояс.
